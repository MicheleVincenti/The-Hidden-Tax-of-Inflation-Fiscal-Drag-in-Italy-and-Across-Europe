# Fiscal Drag Analysis

This folder contains the Stata replication pipeline for the empirical analysis of fiscal drag in the Italian personal income tax system (IRPEF) over the 2020–2024 tax years.

The workflow imports and prepares administrative tax data from the Italian Ministry of Economy and Finance, reconstructs statutory IRPEF liabilities, constructs inflation-indexed counterfactual tax schedules, estimates fiscal drag across income cells and generates the main empirical outputs of the research project.

The analysis uses 2020 as the base year for the counterfactual indexation exercise.
