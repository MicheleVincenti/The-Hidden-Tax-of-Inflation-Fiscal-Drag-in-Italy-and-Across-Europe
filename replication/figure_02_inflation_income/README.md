# Figure 2 — Inflation and Household Disposable Income in Italy

This folder contains the data, Stata code and graphical output used to reproduce Figure 2 of the research project.

The analysis combines annual HICP inflation data from Eurostat with quarterly gross disposable income data for Italian households from the ECB Data Portal.

The Stata workflow imports and transforms the original data, aggregates household disposable income to annual frequency, constructs nominal and real income growth rates, and generates the final figure.
